# FunkinNX

Welcome to FunkinNX, where we take the popular rhythm game Friday Night Funkin' and it's many modifications and port it to the Nintendo Switch Device! (Huge thanks to [Andres_Github/Slushi-Github](https://github.com/Slushi-Github) for adding dkp support for hxcpp & lime, without them this project wouldn't be possible!)
